## Overview

Geo Jumping is a dynamic 2D platformer where players navigate through challenging levels filled with obstacles. Developed using Unity and C#, the game offers an engaging experience with smooth controls and vibrant visuals.

## Installation & Setup

Clone and open the Unity project:

```bash
git clone https://github.com/pranavboyapati/Geo_Jumping_Game.git
cd Geo_Jumping_Game
```
Then, open the project using any version of the Unity Editor released after 2021.
